# Phase 2 — Register Pty Ltd yourself (BizPortal / CIPC)

**Target cost:** R50 name reservation + R125 private company = **~R175** (card).  
**Portal:** https://www.bizportal.gov.za (also via https://www.cipc.co.za)

## Before you open BizPortal

- [ ] [IDENTITY.md](./IDENTITY.md): legal name shortlist, full street address, director ID details ready
- [ ] SA ID / Smart ID (BizPortal director verification)
- [ ] Card for payment
- [ ] Prefer **standard short MOI** (CoR 15.1A) — do not pay for a custom MOI

## Steps

1. Create or sign in to your **CIPC / BizPortal** customer profile.
2. **Reserve name** (R50): submit 1–4 names in preference order, starting with `Vlyt (Pty) Ltd`.
3. Start **Private company (Pty) Ltd** registration with the reserved name.
4. Capture company, director, and incorporator details — address spelling must match IDENTITY.
5. Complete **director verification** and pay **R125** (or the combined amount shown).
6. Download and store offline + in a password manager / drive:
   - [ ] COR14.3 / registration certificate
   - [ ] Company registration number
   - [ ] MOI
   - [ ] Director details printout
7. Paste **exact** legal name, reg number, and address into [IDENTITY.md](./IDENTITY.md).

## After registration

- [ ] Diary **CIPC annual return** (~R100/year if turnover &lt; R1m) so the company is not deregistered
- [ ] Note any SARS income tax number BizPortal issues (out of scope for Play, useful later)
- [ ] Proceed to [03-domain-email-site.md](./03-domain-email-site.md) to put the legal name on https://vlyt.app/company/

## Do not

- Pay third-party “register my company” upsells unless you want them — DIY is intentional
- Start the Play org payments profile before you have D-U-N-S ([04-duns.md](./04-duns.md))
